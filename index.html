Notebook Lab

Décrivez votre objectif et le modèle écrit la cellule : analyse Python, graphique interactif, scène 3D ou jeu. Les cellules JavaScript, Python, C, Lua, Clojure, SQL, HTML et les contrôles partagent les mêmes variables : déplacez un curseur et les résultats s’adaptent. Demandez une modification et le modèle révise la cellule ; en cas d’échec, il lit l’erreur et la corrige. Commencez avec 84 carnets, dont un système solaire 3D, un jeu d’arcade et un écosystème vivant, créés avec quelques prompts.

  • Cellules générées à partir de vos données
  • Python & NumPy via WebAssembly
  • État partagé entre langages

Sous le capot

Conception technique

Des conventions communes permettent à une seule personne de maintenir plus de 220 applications.

Sans étape de compilation

Modules ES natifs avec Preact et HTM via des import maps. Sans bundler ni transpileur : le code source est directement exécuté.

Modèles indépendants du fournisseur

Une couche de streaming commune à OpenRouter, LM Studio et aux serveurs compatibles OpenAI, avec des agents de code locaux (Claude Code, Codex et autres) proposés comme modèles dans l’atelier privé.

Stockage local par défaut

Le travail est enregistré dans le stockage privé du navigateur dès la première visite, ou dans un dossier choisi avec l’API File System Access. Les nouveaux enregistrements s’ajoutent sans écraser les générations précédentes.

Vérifier chaque résultat

Le code généré est exécuté dans des cadres isolés, puis mesuré : rendu, capture d’écran, relecture par le modèle ou session XR émulée.

Dépendances intégrées et figées

Chaque bibliothèque est fournie par le site et inscrite dans un manifeste. Les moteurs copiés dans les projets sont vérifiés à partir d’empreintes figées.

Tests sans npm

Tests unitaires avec node:test, complétés par le rejeu de parcours utilisateur et des captures de régression visuelle pilotés par un petit client Chrome DevTools Protocol.

Essayer les projets

Vos données, vos modèles

Votre travail reste dans le stockage de votre navigateur. Avec Chrome ou Edge, vous pouvez également choisir un dossier sur votre ordinateur.

  1. Ouvrir un projetAucune configuration : votre travail est enregistré dans ce navigateur.
  2. Connecter un modèleUtilisez LM Studio, un serveur compatible OpenAI ou votre clé OpenRouter. Les prompts sont envoyés uniquement au fournisseur choisi.
  3. Choisir un dossierFacultatif : conservez les fichiers sur votre disque. Le navigateur mémorise le dossier et demande l’autorisation de rétablir l’accès.
