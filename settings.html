Votre serveur de modèles local

Connexion directe

Le navigateur communique directement avec votre serveur LM Studio ou compatible OpenAI. Les requêtes ne transitent pas par ce site.

  1. Démarrez le serveur et chargez un modèle. Dans LM Studio, activez CORS dans les paramètres développeur ou exécutez lms server start --cors.
  2. Ajoutez l’adresse du serveur ci-dessous ; LM Studio utilise généralement http://localhost:1234.
  3. Cliquez sur Ajouter et tester, puis sur Autoriser si Chrome ou Edge demande l’accès au réseau local.

Et ensuite

Un dossier racine, un sous-dossier par application

Les applications créent un petit fichier de registre et un dossier distinct pour chaque projet utilisé, comme prompt-gallery ou game-forge-v2. Par défaut, les enregistrements s’ajoutent sans écraser les précédents.
